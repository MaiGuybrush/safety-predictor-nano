# Argus Safety Predictor Nano 使用者操作手冊

歡迎使用 **Argus Safety Predictor Nano（安防監控系統樹莓派版）**。本系統為專為邊緣運算裝置（如 Raspberry Pi 5 / ARM64 環境）設計的高效能即時目標偵測與影像安防推論系統。

本手冊提供系統 Web 管理介面的完整操作指引，協助您快速完成攝影機串流配置、AI 模型管理、ROI 偵測區域劃定以及即時影像監控。

---

## 系統核心特色

- **邊緣最佳化架構**：針對 CPU 推論深度優化，支援 ONNX Runtime、PyTorch 與 NCNN 格式，在低功耗邊緣設備維持低延遲與高幀率。
- **動態熱重載 (Hot Reload)**：所有參數修改與串流變更皆支援即時熱重載，儲存後立即生效，無需重啟服務。
- **多路串流與單路模型覆蓋**：支援 RTSP 多路即時攝影機串流，每路攝影機皆可獨立指派專屬 AI 模型或繼承全域模型。
- **UMS 雲端模型同步**：無縫整合 UMS 平台，支援專案模型與版本一鍵線上拉取與離線快取同步。
- **自訂 ROI 警戒區域**：內建視覺化多邊形劃定工具，即時比對目標偵測結果，精準告警。
- **PPE 工安防護與規則引擎**：支援安全帽/反光背心雙模檢測、外部設備狀態同步與複合工安條件規則判定。

## 連線與進入系統

在瀏覽器網址列輸入系統設備 IP 與連接埠即可進入控制台：

```text
http://<裝置-IP>:8188/
```

預設連接埠為 `8188`。若在本地本機端測試，可直接開啟 `http://localhost:8188/`。
