# 02 — Master-Detail 串流主清單與右下方單一串流編輯器 (Stream Master-Detail Interaction Engine)

**What to build:** 
實作 Master-Detail 主從式串流編輯引擎：左側僅展示精簡的「串流主清單（含 +新增 / ✕刪除）」；點選任一串流時，右上角預覽即時切換至該鏡頭，右下方編輯卡片即時載入該串流的 URL、Label、Camera ID、獨立模型與 ROI 狀態，並雙向即時同步。

**Blocked by:** 01（100vh 滿版 CSS 容器與雙視圖切換）

**Status:** ready-for-agent

- [ ] 左側渲染精簡的串流選擇列（每列顯示 `STREAM #{idx} [標籤]` 與 `[✕ 刪除]` 按鈕，當前選中項具備霓虹綠高亮邊框）。
- [ ] 點選左側串流列時，右上角 `<img id="preview-cam-feed">` 即時切換至該鏡頭畫面（`/video_feed/{idx}`）。
- [ ] 右下方渲染當前選中串流的「專屬編輯卡片」，提供 URL、畫面標籤、鏡頭 ID 與自訂獨立模型輸入欄位。
- [ ] 實作雙向即時同步：在右下角編輯標籤或屬性時，即時更新記憶體資料與左側列表對應項目的顯示文字。
- [ ] 實作「+ 新增串流」與「✕ 刪除串流」之動態主從狀態重編與邊界檢查（至少保留 1 筆）。
