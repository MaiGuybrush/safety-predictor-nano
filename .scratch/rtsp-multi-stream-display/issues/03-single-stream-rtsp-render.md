# 03 — 單路 RTSP 推論結果寫入畫面

**What to build:** 讓瀏覽器在 RTSP 模式（單一串流）下能即時看到攝影機畫面，並在畫面上疊加 YOLO 偵測框與類別標籤。這是整個功能的核心：推論完成後，將標注過的影像幀推入 Web UI 串流，使 `/video_feed` 端點輸出有內容的畫面。本 ticket 假設只有一路串流，且使用全域模型（不涉及 per-stream 模型設定）。

**Blocked by:** 02（需要視訊區塊存在才能驗證畫面顯示）。

**Status:** ready-for-agent

- [ ] 主推論迴圈（RTSP 路徑）在取幀並完成推論後，對原始幀繪製偵測框（綠色矩形）與標籤（類別 + 信心度），並在左上角疊加串流來源標籤。
- [ ] 繪製完成後，將標注幀以 JPEG 格式（品質 80）編碼，寫入 `web_ui.LATEST_FRAME`。
- [ ] 若該輪未取到幀（`get_latest_frame()` 回傳 `None`），`LATEST_FRAME` 保持前一幀不清除，瀏覽器顯示靜止的最後一幀。
- [ ] 瀏覽器打開 `/video_feed` 時，能看到來自 RTSP 串流的即時畫面（非 NO SIGNAL）。
- [ ] 有偵測目標時，畫面上出現綠色偵測框與 `Class X (0.xx)` 標籤，框的位置與目標物體對齊。
- [ ] 無偵測目標時，畫面仍正常顯示，無崩潰或例外。
- [ ] 切換至 video 模式，原有影片播放與偵測框邏輯不受影響（迴歸驗證）。
