# 02 — Web UI 廠區下拉選單、唯讀端點預覽與連線測試整合

## Parent
#55 Feature: UMS 廠區化配置與網卡自動偵測機制
Gitea Ticket: #57

## What to build
重構 Web UI 進階設定中 UMS 服務端點管理面板。由後端動態提供可用廠區清單（oa, fab1, fab2...），前端以下拉選單呈現；移除動態增刪端點與自訂輸入框，改為切換廠區時即時唯讀呈現主備端點網址；表單儲存與連線測試均以選定廠區驅動。

## Acceptance criteria
- [x] 後端提供 API 或於頁面載入時注入所有可用廠區與對應主備端點對照表。
- [x] Web UI 以下拉選單讓使用者選取 ums_fab，並即時在下方以唯讀 Badge/清單預覽對應的主備端點網址。
- [x] 移除手動增刪端點按鈕與自訂 URL 輸入框。
- [x] 點擊「測試連線」時以所選廠區端點執行連線測試，並在前端正確反應用戶端健康度狀態。
- [x] 儲存設定時將 ums_fab 正確持久化寫入 config.yaml，且不包含 ums_base_urls。
- [x] 新增或更新 Web UI 設定儲存與連線測試之整合測試。
